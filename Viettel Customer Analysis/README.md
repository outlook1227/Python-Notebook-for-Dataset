# Viettel Customer Churn Prediction

This project builds a machine learning pipeline to predict telecom customer churn.

## Pipeline
- Data preprocessing and feature engineering (missing values, outlier handling, skewness transformation)
- Model training using Logistic Regression, Random Forest, XGBoost, and LightGBM
- Evaluation using ROC-AUC, KS statistic, and SHAP interpretation

## Results
The best model achieved **ROC-AUC = 0.88** on the test dataset.

## Tech Stack
Python, Pandas, Scikit-learn, XGBoost, LightGBM, SHAP
